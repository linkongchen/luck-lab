# 好运气实验室 · The Luck Lab

**[在线试玩：好运气实验室](https://linkongchen.github.io/luck-lab/)**

无需安装或登录，手机和电脑均可打开。

一个中文互动概率实验：让 1,000 位参与者在相同规则下抽奖，观察整体分布和每个人的经历。

## 试玩

直接用浏览器打开 `dist/index.html`，或在此目录运行：

```sh
node serve.mjs
```

本机地址：<http://127.0.0.1:4173/>。不需要 `npm install`，没有运行时依赖。

## 已实现

- 0.1%–20% 的基础中奖率，每人 10–300 次抽取。
- 普通抽奖、50 抽保底、稀有掉落三个预设。
- 可选择 20 / 50 / 100 抽硬保底，每次中奖后重新计数。
- 开始、暂停、继续、直接完成、同一实验重播、更换随机种子。
- 1,000 人可点击的分布图，支持方向键选择个人。
- 每个人逐次中奖记录，以及最幸运 / 最不幸运参与者入口。
- 零中奖人数、平均中奖次数、最高中奖次数和直方图。
- 保底与无保底使用相同随机数，便于比较规则的影响。
- 分享链接包含规则、版本和随机种子，可以重现相同结果。
- 桌面和手机宽度的自适应布局；离开标签页自动暂停。
- 浏览器内计算，无登录、数据库、广告、追踪或 AI 接口费用。

## GitHub Pages 发布

`dist/` 是完整的静态网站；CSS 与 JavaScript 都使用相对地址，可部署在仓库子路径下。没有必须执行的构建步骤。

`.github/workflows/pages.yml` 会在 `main` 更新时检查 JavaScript 语法、运行概率测试，然后只将 `dist/` 发布到 GitHub Pages。仓库 Settings → Pages 的 Source 应选择 GitHub Actions。

`127.0.0.1` 仅供本机试玩。朋友可以使用发布后的 Pages 网址；网站内的分享按钮会自动使用当前域名生成可重现实验链接。

## 模型约定

普通抽奖使用固定概率的独立伯努利试验。抽取 n 次后一次未中的理论概率为 `(1-p)^n`。
期望中奖次数 `n*p` 不是个人保证。每个实验的人数分布可以偏离理论值。

硬保底的第 H 抽必中奖，普通中奖也会重置计数。每人 n 抽至少中奖 `floor(n/H)` 次。
此模型不包含软保底、概率递增、大小保底或真实游戏账号规则。

为保证链接可重现，实验使用固定算法的种子伪随机数；新实验的种子通过浏览器加密随机接口取得。
修改随机算法时需要更新分享链接版本，避免旧链接对应不同结果。
